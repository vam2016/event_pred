# event_pred

R Shiny 生存数据模拟与事件数/目标日期预测平台。当前源码版本为 **v0.35.0开发稿（待复核）**，已验证版本为v0.19.0，中文界面，时间单位可选日、周、月，默认月。

**当前优先目标：完成 1.0 核心开发并发布。** 首版范围收敛为未来事件数、达标日期和生存数据生成三个入口，保留合并/已知两组、参数/ADTTE CSV 输入、时间与参数换算及核心工作手册。完整开发稿保留，已有功能可继续完善；高级研究分批安排到 [2.0 开发计划与工作流程](docs/V2_0_DEVELOPMENT_PLAN.md)。首版边界和发布门槛见 [1.0 发布计划](docs/V1_0_RELEASE_PLAN.md)。

独立入口 `app_core.R` 标记 **1.0.0-rc.1**，核心本机必要检查已通过，详见 [核心验证报告](docs/CORE_VALIDATION.md)。核心候选版另在 3839 启动，现有 v0.19 预览保持不变。GitHub main 使用核心入口，`development/v0.35` 保存完整扩展稿；下文历史记录不代表首版全部开放或验证通过。尚未部署公网。

## 时间与参数说明

1 周 = 7 日；1 月 = 365.25/12 日，表示固定经过时间。切换单位同步转换已填时间、速率、Gamma 先验 rate 与 log(eta)先验均值。日期保持不变；最近成功结果保留当时单位。内部引擎为日，导出同时标明输入/显示单位与换算系数。

所有输入旁的“?”可查看含义、范围、单位与输入建议。中位生存、率和先验需按研究依据设定；默认值和历史讨论中的12个月仅用于演算。完整说明见[参数说明](docs/PARAMETERS.md)，推导与算例见[方法页](docs/METHODS.md)。

指数可用中位时间或风险率输入；Weibull 可用中位时间或尺度 eta；Log-normal/Log-logistic 可用中位时间或对数位置 mu。独立指数脱落可输入风险率或指定窗口概率。切换形式保留当前分布，结果列出等价参数并支持 CSV。

首页按需求进入：未来事件数、达标日期、设计阶段生存数据、IA→Final条件模拟、重复试验设计评价、两阶段事件数重估、历史IA调整推断、PFS/OS联合模拟、批量研究与参数校准、联合终点设计研究。每个入口只显示相关参数与结果；隐藏分支不参与参数解析。事件数入口不要求D*，固定DCO模拟不要求目标与达标窗口。回测、q情景和后验诊断按适用情况显示。

## 统计工作手册

“方法与推导”页提供40个章节入口（新增章节待复核），各模型依次说明用途/参数、似然推导、年龄条件预测、平台操作、算例和结果核对。另有固定参数、Bootstrap、Gamma、Weibull MCMC、未来过程、分组、AIC混合、回测及输出解释。支持Markdown与HTML阅读版下载和浏览器打印/保存PDF；目录和公式适配窄屏。详见[生存模拟与事件预测工作手册](docs/METHODS.md)。新增IA→Final章节说明条件抽样、原风险集、NR、参数不确定性及预测概率。

## 输入

- **参数输入**：无需文件。输入事件分布、当前队列人数/年龄与未来入组计划；启动前模拟将当前人数、事件数和截点设为 0。
- **ADTTE 数据**：CSV、XPT 或 SAS7BDAT。必填 `USUBJID, PARAMCD, STARTDT, ADT, AVAL, CNSR`；文件 AVAL 单位可单独选日/周/月。终点、分析标志、AVAL 日期加项和永久退出随访编码在界面设置。

详细格式及末次确认早于截点时的处理见 [数据接口](docs/DATA_CONTRACT.md)。模板为合成数据。

## 功能

|模式/模块|支持内容|
|---|---|
|数据拟合|指数、Weibull、PWE、Log-normal、Log-logistic、KM＋指定指数尾部、Gompertz、Cure-Weibull|
|参数模拟|指数、Weibull、PWE、Log-normal、Log-logistic、Gompertz、Cure-Weibull、双成分 Weibull|
|不确定性|固定参数、Bootstrap、指数/PWE Gamma 后验、Weibull MCMC；数据模式入组/脱落 Gamma 后验|
|未来过程|恒定/分段入组率、独立永久脱落、风险倍数、固定新增事件报告延迟|
|结果|累计事件曲线、逐点 95% 区间、目标日期分布、达标概率、AIC 预测混合|
|评价|历史截点回测、事件数误差/覆盖、Brier、窗口截断日期评价、风险情景|
|推导与导出|条件生存、似然与后验、分布反演、链迹与 ESS；CSV/JSON/Markdown|

Gompertz、Cure-Weibull 支持右删失数据 MLE 与 Bootstrap，显示数值拟合诊断；治愈比例边界或曲率不足时拒绝。双成分 Weibull 仍为给定参数模拟，不估计盲态成分，不声称实现 BayesPET。支持合并及已知组别独立建模，尚无组内协变量模型；历史多IA条件续推使用完整实际快照；中心、报告积压和多状态模型见 [开发记录](docs/DEVELOPMENT_PLAN.md)。

## 历史多次IA续推

“IA→Final条件模拟”选择“历史多次IA后的组序贯预测”。文件采用ADTTE长表，并增加平台扩展字段 `IASEQ, DCO`；每个分析保留完整患者快照及两组标签。选择已完成的原分析次序后，只使用从分析1至该次的记录。

填写原完整 `D*`、信息比例、alpha消耗和停止规则；未来从下一原分析继续，历史Z不重抽样。当前已停止时只返回已有决策，隐藏未来模型、窗口和重复数。支持固定参数、Bootstrap、Gamma/MCMC及既有未来过程设置；输出历史/未来路径、条件拒绝概率、停止时间与资源、JSON和复现R脚本。

模板见 [历史IA合成数据](examples/adtte_ia_history.csv)，示例为20/40/60日、20/40/60事件，原最终目标80及比例0.25/0.5/0.75/1。详见工作手册第25章。当前要求历史事件数恰好匹配原目标，不接受历史裁定修订、迟录入、并列超目标或时点变更；本入口未接调整p/CI或确认性目标重估。

## 验证

```sh
Rscript scripts/check.R
Rscript scripts/calibrate.R 30
```

第二条生成合成验证的原始结果、汇总和配置。计算核心与界面分开；测试覆盖输入核对、条件分布、回测信息泄漏、后验数值参照和会话运行。结果见 [验证记录](docs/VALIDATION.md)。内部检查与小规模合成校准不等同于外部研究验证。

Weibull MCMC 采用 log 参数正态先验及随机游走 Metropolis；`posterior` 计算 rank R-hat、bulk/tail ESS。未通过 R-hat≤1.01、两类 ESS≥400 时不生成新预测。参数模式不拟合内部生成的队列。

## v0.7 设计阶段生存模拟

从“生成并分析生存数据”入口设置单组或2–6组、计划总人数、分配权重、各组事件分布与脱落。支持恒定/分段Poisson或固定日程入组、多个固定DCO或事件驱动截点；每次试验在多个DCO使用同一患者轨迹。提供KM、中位时间及区间、固定时点率、在险人数、NR比例与可估计条件下的分布。

指数可输入固定时点生存率，PWE可输入切点生存率与末段率。单次观察数据可导出连续时间或ADTTE；批量导出每轮分析、截点、真值、配置、复现R脚本和报告。ADTTE保留日期取整后的同日起止记录并提示现有预测接口不接受，不移动或删除。复现脚本在源码根目录运行；计算函数位于R/simulation.R。

当前范围为给定参数的数据生成与描述分析，不计算功效/Ⅰ类错误，不实施组序贯或条件续模拟。所有参数均配有说明，时间默认月且支持日/周换算。

## v0.8 任务入口与IA→Final

从“从IA继续模拟Final”入口选择ADTTE、设计模拟的一轮观察记录或内置合成示例。需要IA个体数据，汇总事件数不能重建历史KM。支持合并或1–6个已知组别、拟合或指定分布、Bootstrap/Gamma/Weibull MCMC、按组未来入组/脱落及过程后验、配对q情景、多Final DCO或事件驱动截点。

保留已事件/永久退出历史，按原IA风险集条件续推，输出IA/Final KM、中位时间与变化、固定时点生存率与变化、可估计性、增长概率及MCSE。未达事件目标保留窗口末分析；NR单独标记；失败轮次列出原因及概率界。下载的复现脚本包含IA个体数据。

本入口要求仍随访者确认至IA，暂不补全IA之前的未观察区间；当前事件驱动采用实际发生日期，不含访视/上报机制。

## v0.9 两组重复试验与设计评价

从“评价功效与候选设计”进入，按功效、Ⅰ类错误或候选网格显示参数。Control支持8类参数分布，Treatment按总体PH风险比生成；恒定/分段Poisson或固定日程入组，两组独立脱落。截点可固定DCO或事件目标，未达标按预定规则保留。

标准log-rank采用精确时间风险集公式，Cox采用Efron/Wald。结果包括拒绝率、Wilson区间、MCSE、失败概率界、目标达成、log HR偏倚/RMSE及95%覆盖。相同N/HR多个截点共用患者轨迹并支持配对差值。后台进程分批保存，可取消；未完成结果保留完成轮次及状态。

每情景20–10000轮，可按预定最坏MCSE选择B。结果和失败CSV、配置、复现R脚本、Markdown报告及选定轮次观察数据/ADTTE可以导出。`processx`是新后台依赖；执行`scripts/install.R`检查依赖。手册第16章提供推导、操作与分母解释。

v0.10加入两组NPH固定设计；v0.11增加两组PH组序贯与canonical条件功效，自适应重估仍待开发。没有同步GitHub或部署公网。

## v0.11 组序贯与期中条件功效（D2a）

第五个入口的“分析设计”可选择固定分析或组序贯。组序贯使用两组PH、标准log-rank、事件驱动的2–5次预设分析；选择最终D*、计划信息比例、单/双侧alpha及OBF型或Pocock型alpha消耗。单侧获益可设置非约束性无效Z边界。比例取整为事件数后计算边界，正Z表示Treatment获益。

结果按完整试验统计拒绝率、早期效力/无效停止比例及平均事件数、停止时间、检验次数。选定轮次可查看逐次路径。达到停止规则后不再检验；窗口未达下一目标时不追加检验。未输出停止后未经调整的Cox区间及覆盖率。

“期中条件功效”使用选定模拟轮次已完成分析的Z、计划信息比例和用户指定未来HR，分别计算后续完整路径跨界概率及仅最终一次拒绝概率。它采用canonical正态增量及D×p×(1−p)信息近似；实际ADTTE个体条件预测、预测拒绝概率、事件数重估、约束性beta消耗和序贯调整推断尚待开发。

新增逐次分析/停止汇总/CP CSV；配置保存边界及依赖版本，复现脚本保留取消时已完成试验。手册第18章说明alpha消耗、停止规则、CP条件均值/协方差和操作。运行依赖增加`rpact`和`mvtnorm`，先执行`scripts/install.R`。

## v0.12 实际IA个体条件预测拒绝概率（D2b第一部分）

第四入口先选择“生存估计与IA变化”或“未来拒绝概率”。后者需要已知组别的两组IA观察记录，明确Control；文件支持ADTTE的日期、AVAL单位、终点/分析标志及永久退出编码，亦可使用设计模拟观察记录或合成示例。

历史风险集、事件、退出和ID固定；仅重拟合/抽参数并生成未来。支持给定参数、Bootstrap、指数/PWE Gamma、通过诊断的Weibull MCMC，以及过程Gamma。拒绝路径为一个预设Final DCO/事件目标，或原PH/log-rank方案从首次IA继续组序贯。输出有效决策下拒绝概率、MCSE/Wilson和全部请求的失败概率界、逐次路径及停止观察数据。

组序贯IA已停止时直接返回已有决策；未达下一目标不追加检验。当前IA事件数需匹配原首目标。一次Final需指定唯一DCO和未达窗口规则。结果不输出无关生存变化参数和表格，导出保留原观察历史、边界快照和无损复现。

手册第19章给出个体条件生存、预测拒绝积分、参数不确定性、失败分母及Gamma解析算例。此为给定当前数据的预测，不能解释为从研究起点的功效或Ⅰ类错误；尚未实施事件数重估、调整p/CI或后续IA的历史路径接入。继续仅本机开发。

试用文件`examples/adtte_prediction_ia.csv`是合成120人IA数据：选日单位、研究起点2025-01-01、IA=540日、PARAMCD=OS、文件AVAL单位日/首日偏移1、永久退出CNSR=2、组别变量TRTP、Control组=Control。原IA有41事件；组序贯试用可设最终D*=82、原比例0.5,0.75,1（仅为合成示例规则）。


## v0.13 两阶段事件数重估与离线公式

首页新增“重估两阶段事件数”，选择给定IA Z1的事件数计算，或从起点评价完整设计。采用PH事件信息近似、canonical两阶段正态模型、原计划固定逆正态权重及单侧Final检验。输入预定D1/Dplan、Final事件上限、Treatment分配比例、alpha、未来HR和目标CP；可选择上下限CP或受约束promising-zone规则。给定IA只显示重估事件数、条件错误、可达CP及规则分支。重复评价自动包含HR=1，给出拒绝率/Wilson/MCSE、平均事件数、整数跳变处的一维积分参照、原计划配对比较和无损复现。

本版不将累计log-rank统计量相减后视为独立阶段；canonical模型不读取ADTTE，不生成患者或日历日期。真实生存个体资料的重估及独立增量/条件错误检验构造、从患者生成起点的完整Ⅰ类错误校准仍是下一步。

手册第20章逐步推导组合检验、条件错误保持、CP、事件数解析解、两种规则及完整设计积分。全部882个数学片段预先转换为SVG矢量公式，平台和下载HTML无需加载公式脚本/字体。源码Markdown保留；长公式在窄屏内滚动，打印使用矢量图。修改手册后可按`scripts/render_handbook.cjs`的说明重新生成缓存；固定MathJax 3.2.2引擎及许可证随源码保存。未同步GitHub、未部署公网。
