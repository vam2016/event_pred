## 一、产品范围

1.0 用于单个生存终点的事件数预测、达标日期预测，以及给定参数的生存数据生成。合并数据适用于盲态预测；已知组别时分别建模并汇总。首版最多两组，不提供疗效检验或适应性决策。

首页保留三个任务入口和一个工作手册入口。进入任务后仅填写该任务需要的参数，仅显示该任务的结果。参数输入与 ADTTE 数据输入二选一；数据模拟仅使用参数输入，不要求上传数据。

|任务|必要输入|返回结果|
|---|---|---|
|预测未来事件数|参数或 ADTTE；当前截点；合并/已知组别；事件模型；预测时点；未来入组与独立退出设置|未来新增及累计事件数、事件曲线、条件于给定/拟合参数的逐点预测区间；已知组别时提供各组和总体结果|
|预测达标日期|同上，预测时点改为累计目标事件数 D* 和最大预测窗口|达标时间/日期分布、窗口内达标概率、未达标比例、概率的 Monte Carlo 标准误；D* 包含截至当前已发生事件|
|生成生存数据|总体人数；合并/已知两组与分配比例；各组事件参数；入组计划；独立退出；固定数据截点；随机种子|观察数据、模拟真值、ADTTE 格式数据、KM 曲线及描述性汇总；真值与观察结果分开导出|

参数模式的运行中预测保留当前累计事件数、仍在随访人数及随访年龄信息；已发生事件、永久退出和仍在随访者分别处理。预测使用当前已知信息，不读取未来结局。设计起点的预测将当前累计事件数和在随访人数设为零。

## 二、1.0 功能冻结清单

|保留项|1.0 边界|
|---|---|
|事件模型|指数、Weibull、分段指数 PWE；数据模式采用右删失似然拟合，PWE 切点由用户指定，不自动搜索|
|分组|合并或已知两组；按组设置模型/参数及未来计划，汇总事件轨迹；不从盲态数据估计治疗 HR|
|预测随机性|固定参数或拟合参数代入后的患者事件、入组和退出随机性；明确区间未包含参数估计不确定性，逐点区间不作为同时置信带|
|入组和退出|已有的恒定/分段入组、独立指数永久退出；未来事件风险沿用所选模型（额外风险倍数固定为 1），采用实际事件发生口径（新增报告延迟固定为 0）；迟报及观察选择机制留待后续|
|时间和参数换算|日/周/月，默认月；1 周为 7 日、1 月为 365.25/12 日的经过时间；指数中位时间/风险率、Weibull 中位时间/尺度、退出率/窗口退出概率互换；PWE 风险率随单位换算|
|输入帮助|保留参数旁的含义、单位、允许范围和建议；默认值标明为演算示例|
|数据接口|首版必需 ADTTE CSV 和合成模板；必填 USUBJID、PARAMCD、STARTDT、ADT、AVAL、CNSR，明确日期、AVAL 单位/加项、事件与永久退出编码；已知组别时明确选择组别列|
|观察截止|要求仍在随访者确认至当前截点；缺失确认资料给出具体错误说明，不自动补全未观察历史|
|输出和导出|表格 CSV、配置 JSON、简要报告；模拟观察/真值/ADTTE 分开下载；保留随机种子和实际提交配置，编辑输入不改变既有结果|
|计算控制|沿用已有必要进度与错误反馈；在发布环境设定可用重复数/人数上限，实际数值在发布检查后确定；不开发新研究队列或持久后台库|
|工作手册|仅对应首版入口、模型、数据和输出，Markdown 为内容源，提供公式可显示的页面/离线阅读版|

目标已达到、预测窗口内未达到、事件风险或入组为零、拟合失败等情形必须明确返回状态；不能为展示日期删除未达标模拟轮次。参数模拟和数据拟合分别说明适用条件。

XPT/SAS7BDAT 导入、Bootstrap、后验预测以及其他已有功能仍保留在完整开发入口中，可继续整理开发并分批开放。当前核心候选稿不承诺这些分支；若后续有明确首版需求，以小范围调整和对应验证记录更新清单。

## 四、代码与界面整理

保留 v0.35 完整开发稿及历史文件，从核心模块整理独立的 1.0 发布入口与依赖清单。当前 app.R 会无条件加载扩展模块，首版需要同时收敛模块加载、服务器注册、导航、配置解析和导出路径；仅隐藏导航不足以隔离扩展代码。

优先复用已经存在的核心实现和 v0.19 历史检查，不重写预测算法。剥离依赖时保留核心所需工具函数；若通用工具与高级模块耦合，抽出必要部分，避免新增统计功能。

入口内按“输入方式 → 合并/分组 → 模型 → 本任务参数 → 运行”排列。可选设置折叠，只有涉及的字段参与提交。事件数入口不要求 D*，达标日期入口不要求多余的固定预测时点，数据生成入口不显示预测/检验参数。

界面采用简洁中文名称、统一表格/图形和参数帮助，不增加账号体系、项目管理、多租户权限、协作审批或新的复杂平台组件。沿用已有样式作整理，首版不安排整套视觉重建。

## 五、核心工作手册

正文保留以下八部分，详细推导仍需足够供统计师理解实现，不把删减范围等同于删去必要方法说明。

1. 三个任务的操作与完整算例。
2. 时间起点、当前截点、随访年龄、事件/右删失/永久退出、ADTTE 编码和模板。
3. 条件生存 S(a+u)/S(a)、条件事件概率及独立退出下的累计事件积分；当前事件数与未来患者贡献的关系。
4. 指数的生存函数、右删失似然、参数换算、条件事件抽样和可独立核对的解析例子。
5. Weibull 的参数定义、右删失似然、累计风险反演和条件抽样；说明形状参数与时间单位的关系。
6. PWE 的分段累计风险、暴露/事件似然、切点和尾段处理、反演及零风险段。
7. 入组、独立退出、按组预测汇总与模拟数据生成；区分观察值和真值。
8. 逐点预测区间、达标与未达标、Monte Carlo 误差、模型假设、导出和复现；明确参数代入预测的区间边界。

原完整扩展手册留在开发资料中，不作为首版主导航。符号、代码参数和界面名称一致；公式显示是首版验收的一部分。

## 七、发布门槛

- 三个入口能独立完成一次操作，任务切换不泄漏无关字段；错误输入给出可执行的修正说明，失败不覆盖最近成功结果。
- 指数模型条件概率及未来入组/独立退出期望采用独立解析参照；Weibull/PWE 用独立累计风险/条件分布参照。统计容差在执行前记录，模拟比较按 Monte Carlo 误差解释。
- 单位换算、各组和总体计数、当前已发生事件、永久退出、AVAL/日期/CNSR 一致性、零风险及未达标处理通过必要边界检查。
- 同一配置/随机种子可复现；CSV/JSON/报告对应实际提交配置。观察与真值不混用；真实上传文件不进入 Git 仓库或公共示例。
- 核心手册公式、目录、参数名称和算例与候选版一致；主入口不存在未开放高级功能链接。
- 发布环境核心流程通过，依赖与启动说明齐全；v1.0.0 版本号只在以上检查通过后使用。历史 v0.19 的通过记录不自动覆盖整理后的候选版。

进度按“核心候选稿 → 核心检查通过 → 已上线”报告，不按高级模块数量换算完成百分比。后续迭代每次增加少量明确需求，独立登记验证范围。
