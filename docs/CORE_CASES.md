# SurvCast 2.0 合成案例

案例版本：2.0.0-dev；所有记录均为合成教学资料。案例设置来自R/core_cases.R，与页面和下载JSON同源。

在在线工作手册顶部选择案例，下载案例JSON和案例复现R脚本；需要ADTTE时另下载案例CSV。把JSON与R脚本放在同版本源码根目录，执行 `Rscript survcast_case_replay.R`，输出以survcast_case_开头的结果CSV。四个案例请分别保存，文件名相同会覆盖前一个案例。

复现脚本读取下载JSON中的参数及合成记录；不读取当前页面参数。需相同R和依赖环境。CSV可导入页面，ISO日期、AVAL单位日、日期加项1、退出编码2；手工设置其余参数后再核对结果。

## 对数时间：条件事件数（log_time）

1. 选择未来事件数、参数输入、合并，单位日，研究起点2025-01-01，DCO=20。
2. 当前仍随访10人、已记录事件0、相同随访年龄20日；Log-normal，中位时间50日、sigma=0.8。
3. 未来入组0、永久退出率0、上报延迟0、风险倍数1、窗口80日、次数100、种子6401；运行后核对累计/新增读数。

核对： 初始累计事件为0；新增与累计相同；条件事件概率为1-S(100)/S(20)，不是1-S(80)。固定参数区间不含参数估计不确定性。

## ADTTE：患者Bootstrap（bootstrap）

1. 下载案例ADTTE CSV，选择未来事件数、ADTTE、合并、日、DCO=100，OS，无分析标志筛选，CNSR退出编码2。
2. 选指数、Weibull、PWE；PWE随访切点20,50；患者Bootstrap；未来入组0、退出率0、延迟0、风险倍数1。
3. 窗口80日、次数100、种子6401；核对计算次数CSV及逐轮失败CSV。

核对： 60人：36事件、6永久退出、18仍随访；初始累计事件36。每个模型请求=有效+失败，失败不补抽。

## 达标：历史回测与风险情景（validation）

1. 下载案例ADTTE CSV，选择达标日期；合并、日、DCO=100，OS，无分析标志筛选，退出编码2；仅指数、固定拟合参数。
2. 目标45、未来入组0、退出率0、延迟0、风险倍数1、窗口80日、次数100、种子6401；运行预测。
3. 回测与情景：历史截点40,60，历史剩余人数0,0，历史入组率0,0；风险倍数0.75,1.25，分别运行并核对CSV和图。

核对： 历史评价止于100日，实际仅36事件、未达45。风险基准1自动保留；独立情景MCSE与预测区间不同。

## 生成数据：事件驱动截点（event_simulation）

1. 生成生存数据：日、研究起点2025-01-01、OS、20人、5试验、种子7301、单组A、权重1。
2. A组指数，中位时间13.862943611198906日，退出率0；恒定入组率2人/日。
3. 事件驱动、总体目标10、最大研究窗口20日、固定随访时点4,6,9；核对实际DCO、达标比例、观察与真值导出。

核对： 每个试验保留一条实际DCO；未达标也按20日分析，达标概率分母为全部5个试验。潜在真值不进入KM。

案例只示范已验收的核心方法。它们不替代独立方法检查，也不证明临床假设、覆盖率或功效。
