## 交付与输入契约

核心事件数/达标日期预测新增“回测与情景”，读取最近成功预测的规范化患者记录、模型、主参数和单位。后续编辑主参数不重写辅助结果；辅助提交失败显示原因且保留上次成功结果；新预测或切换任务清空旧辅助分析。没有新增首页研究任务。

历史回测仅用于ADTTE、实际发生口径，填写1–6个不同历史截点及逐截点历史剩余人数/恒定入组率；两组分别填写计划。不使用当前剩余人数或最终文件的未来入组数代替当时计划。训练只保留截点前入组记录，截点后的事件/退出截断为仍随访，重新拟合历史快照；最终实际事件只用于评分。评价窗口末为min(历史截点+原预测窗口,原DCO)。保存历史配置、训练快照、模型结果、请求/有效次数及逐轮/候选失败。

事件数任务显示预测中位数减实际的误差、逐点事件数区间、本次包含指标及区间宽度，不评价隐藏的占位目标。达标任务显示窗口内达标概率与MCSE、Brier、实际/预测时间和有限时间误差。“窗口截断日期区间含实际”针对含Inf质量的截断量；不是窗口外日历日期覆盖。少数截点的包含指标不构成覆盖率校准。单一最终文件不能重建历史访视更正、报告版本或解决信息性删失。

风险情景填写1–5个不同累计风险倍数q∈[0.1,5]，自动保留基准1；固定原患者、入组、退出计划，调整累计风险为qH(t)，两组同比例调整各自基准风险。每个情景用不同明确种子；基准种子保持原值，后续种子按(seed+104729×序号)模2^31计算。比较窗口末平均事件数或窗口内达标概率与基准的差，MCSE为两个独立模拟方差的和再开根号；没有逐轮配对证据，不给配对MCSE。基准减自身的差和MCSE为0。有限模拟误差不代表模型或参数不确定性。

固定拟合参数支持五种核心模型；Bootstrap仍仅指数、Weibull、PWE，组内重抽完整患者、重拟合后预测原队列。失败不计为未达标且不补抽，超过10%停止该次预测。风险情景单项失败保留错误和输入配置，其余成功项继续；基准失败停止整批。回测任一截点整体失败则不发布本次部分结果。候选模型失败、逐轮失败分开导出。

汇总/次数/两类失败CSV、配置JSON及回测历史计划CSV同源冻结；CSV保留连续日和原单位，入组率列明确每连续日及每原单位。窗口外时间表格为空、CSV保留Inf、JSON为null。逐人复现输入RDS含用户本机规范化数据及参数覆盖模型，与实际下载的R脚本重放；这类用户下载不纳入Git源码。JSON本身不包含完整患者记录。
