# v0.35 需求入口与输入/输出

**2026-10-05 核心候选版更新：** 1.0.0-rc.1 的本机必要检查通过，实际范围见 [核心验证报告](CORE_VALIDATION.md)。目标部署环境待检查；v0.20–v0.35 高级新增分支仍待专项验证。以下保留此前版本和安排的历史记录。

**此表描述完整开发稿，非 1.0 发布范围。** 2026-10-05 起首版收敛为三个核心入口，开放模型、输入和结果以 [1.0 发布计划](V1_0_RELEASE_PLAN.md) 为准；其他入口保留为后续开发资料。独立核心候选入口已写入，尚未实施发布验证；见 [核心开发状态](CORE_DEVELOPMENT_STATUS.md)。

本表是代码交付范围说明，没有进行运行或结果复核。23个入口；v0.35新增实际IA期望反校准和Panel多状态模型两个独立需求。时间显示日/周/月、默认月；模型与导出内部连续日。选择JSON时仅用文件冻结参数。

|入口|本次需求|参数或资料|主要结果|限制|
|---|---|---|---|---|
|未来事件数|给定IA后的累计数|参数或ADTTE、事件/未来过程|事件数曲线和预测区间|与报告发布口径区分|
|达标日期|给定目标事件数|参数或ADTTE、目标和窗口|日期分布/窗口达标概率|未达轨迹保留|
|设计模拟|生成单终点患者|组别模型、入组/退出、DCO|观察/真值、KM和生存摘要|一次设计生成|
|IA→Final|从已有记录续推|ADTTE/冻结IA、原检验/未来参数|未来拒绝和资源|条件预测不是设计功效|
|设计评价|两组固定/组序贯试验|模型、效应、N/D*及分析|功效/Ⅰ类错误和路径|预定规则|
|事件数重估|两阶段规划或实际IA|正态模型或独立队列|原/重估事件与拒绝|对应专门理论范围|
|历史IA推断|原分析历史|完整ADTTE快照与原设计|重复/阶段排序调整推断|不能重建未知历史|
|PFS/OS联合模拟|同患者联合资料|三转移模型/时钟/过程|两终点、状态区间和真值|不是一般联合正式适应|
|联合终点设计研究|一次Final多重性|联合生成、终点分析/规则|联合声明及同轮规则差|未知/失败完整分母|
|独立队列重估研究|重复原/重估设计|PH模型及原规则|拒绝/事件/资源及配对|独立新患者|
|实际IA条件批量|运行中冻结资料批量|既有或独立新队列IA|条件拒绝/资源/情景|数据随配置冻结|
|异质患者研究|协变量/层/中心/脆弱性|共同模型及异质参数|预定分析比较/恢复|潜在脆弱性隔离|
|共享患者重估|构造后的共享风险证据|已知风险或精确共同队列|条件错误/证据/区间|不支持一般未知基准Cox|
|多状态条件预测|实际状态拟合/续推|精确状态CSV/双终点ADTTE或参数|转移拟合/两终点计数日期|精确路径限定|
|联合序贯与重估|已知风险联合证据|原混合及IA、事件计划|联合声明和预定重估|状态无关指数死亡|
|柔性与盲态预测|拟合/事件数/日期|精确/区间资料或参数|模型参考和条件预测|RP/I-spline等六候选；固定外部HR盲态/工作模型|
|访视与报告过程|观察模拟或已知积压|访视/退出/报告参数或清单|区间/临床中央数/IPCW/发布|已检测状态退出，已知清单|
|批量研究与参数校准|原批量/assurance/Weibull|基准及情景，或两个生存率|方法与分母/参数等价|研究库的通用入口|
|多臂与两阶段|共享对照/选臂/2-in-1|臂表、HR、阶段/校正规则|有效臂声明/FWER/逐臂/交集/协方差/近似区间/资源|新Stage2患者；固定/事件目标，Cox/Dunnett型渐近或固定landmark精确分支|
|设计搜索与独立确认|预定有限候选|共同设计、候选N/日历上限/D1/D2、真值/MC门槛|搜索资格/冻结选择/确认界|只覆盖新多臂/两阶段引擎，不能追加B|
|期望事件反向校准|单一参数的确定性反求|模型、有限均匀入组/退出、目标/界|q/N/DCO或生存率、残差/曲线|不是IA条件预测/功效/预测区间|
|IA期望事件反校准|单变量/多目标规划反求|风险年龄人数或连续日IA；模型/未来计划/目标/界|q/N/mu/DCO、偏差/整数方案/局部识别|非真实HR/机制估计，无预测区间，独立JSON/RDS|
|Panel多状态模型|拟合/参考或条件期望计数|七列访视状态或三常数率/状态人数|三率、过滤状态、联合生存和期望事件|可忽略访视/退出；常数Markov，无预测区间/正式适应|

本机研究库支持按研究家族载入结果、同引擎缺失键续跑和常规研究追加子研究；搜索确认家族单独禁用追加。历史版本可以查看，不能跨引擎混入轮次。反向校准独立JSON/RDS导出，不假设加入重复试验库。
