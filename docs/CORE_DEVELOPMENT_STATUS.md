完整开发目录使用 `shiny::runApp("app_core.R", host="127.0.0.1", port=3839)`。核心包或 main 分支使用 `shiny::runApp(".", host="127.0.0.1", port=3839)`。已启动候选入口 3839，原已验证 v0.19 的 3838 预览保持不变。没有部署公网；高级新增分支不随本次核心检查声明通过。
