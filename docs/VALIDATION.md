## 小规模合成校准（保留v0.2实验）

本轮未重跑完整校准。以下为 v0.2 的历史结果；v0.4 修改了数值拟合检查、混合反演及回测接口，这些历史覆盖率不能作为 v0.4、v0.5 或 v0.6 的重新校准结果。

执行 `Rscript scripts/calibrate.R 30`：5 个生成过程 × 30 个试验 × 3 种参数处理，共 **450 次试验预测运行，1,650 条模型评价记录**。试验级运行失败 **0**。

- 计划人数：200；真实入组每 2 天 1 人，预测使用恒定率 Poisson 0.5 人/天。
- 研究截点：第 300 天；评价：第 700 天；目标：100 个事件。
- 生成中位事件时间：350 天。
- 形状：指数 1、递增风险 1.5、递减风险 0.7；高脱落 0.002/天；治愈过程治愈比例 0.3。
- 基础脱落：0.00025/天；实际事件与脱落独立。
- 每次预测：300 条轨迹；固定参数/Bootstrap 用指数、Weibull、PWE 和 AIC 混合；共轭模式用指数、PWE 和 AIC 混合。
- PWE 切点：90、180 天；Gamma 事件先验 shape=0.5、rate=50。

输出：

- `validation/calibration_raw.csv`：逐试验误差、覆盖、区间宽度、Brier 和失败信息。
- `validation/calibration_summary.csv`：bias、MAE、RMSE、覆盖率与 Wilson 95% 区间、覆盖率 Monte Carlo 标准误、Brier 和可计算目标日期误差。
- `validation/calibration_config.json`：生成参数、种子和运行环境。

### 选定结果

|生成过程|模型/参数处理|事件数区间经验覆盖率|MAE（事件）|
|---|---|---:|---:|
|指数|指数 / 固定参数|70.0%|9.90|
|指数|指数 / Bootstrap|90.0%|10.23|
|指数|指数 / Gamma|90.0%|9.93|
|递增风险|指数 / 固定参数|6.7%|35.83|
|递增风险|Weibull / Bootstrap|86.7%|16.63|
|递增风险|AIC 混合 / Bootstrap|93.3%|22.03|
|治愈|AIC 混合 / Bootstrap|100.0%|12.83|

固定参数区间没有包括估计参数的不确定性。分布不匹配时，参数后验也不自动修正模型偏差。该实验没有据此改写模型公式或重新标称区间。

每个单元只有 30 个试验：覆盖率结果的 Monte Carlo 误差较大；100% 覆盖也不表示覆盖率已被证明为 100%，Wilson 区间保留了该不确定性。生成入组是规律间隔、预测入组是 Poisson，二者不完全匹配。实验不含正式报告延迟或真实多快照。
