## 本次交付与契约

核心生存数据模拟现可选择固定DCO或首次达到总体目标事件数D*。事件驱动支持单组/已知两组，指数、Weibull、PWE、Log-normal、Log-logistic及恒定/分段Poisson入组；给定参数、简单随机分组、独立永久退出。

- 实际DCO为窗口内第D*个可观察事件的研究时间；同一时点全部并列事件计入，事件数可能超过D*。窗口端点计入，退出早于事件时不计潜在事件，事件/退出恰好并列按事件。截点当天入组、无正随访者不进入观察记录。
- 未达标按最大窗口末分析，达标时间保持缺失；无人入组、零事件和不可达情景均保留在全部试验分母。目标超过计划人数允许用于不可达情景。
- 达标汇总同时给请求/分析/达标/未达标、达标比例及MCSE、全部试验实际DCO分位数和已达标条件时间分位数。零/全达标时经验MCSE为零不证明真实概率为零/一。分位数采用type=1；零达标的条件时间为缺失。
- KM只读取各次实际DCO的观察数据，真值另导出；随机截点的KM与常规log-log区间为描述结果，不声明停止规则下覆盖率、功效或Ⅰ类错误校准。重复试验按各自DCO分析，不是同一研究日比较。
- 最近成功配置冻结；编辑参数/单位或失败提交保留旧结果。配置JSON的未达标时间写作null。截点/达标汇总CSV、报告和复现脚本同源；连续日与所选单位并存，ADTTE日期向下取整、含首日AVAL，同日起止不平移、不丢弃。
